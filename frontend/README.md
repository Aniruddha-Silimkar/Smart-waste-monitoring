
  # Smart Waste Monitoring Interface

  This is a code bundle for Smart Waste Monitoring Interface. The original project is available at https://www.figma.com/design/5tFhKum8AQKxhGJ8LPWSkj/Smart-Waste-Monitoring-Interface.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Deployment

  Set `VITE_API_BASE_URL` to the deployed backend URL in your frontend hosting provider.
  For local development, copy `.env.example` to `.env` and keep the default localhost URL.
